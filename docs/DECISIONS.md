# Architectural Decisions

## 2026-07-16

- Büyük componentler numaralandırılacak (Hero001, CTA001...)
- UI componentleri isim bazlı olacak (Button, Input, Badge...)
- Her component kendi klasöründe bulunacak.
- Her component kendi CSS dosyasına sahip olacak.
- Design Token sistemi kullanılacak.
- Dark Mode ilk sürümde olmayacak.
- Dokümantasyon üç dosya ile sınırlandırıldı.
